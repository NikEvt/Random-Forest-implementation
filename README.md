## О проекте

Данный проект представляет собой практическую работу по **самостоятельной реализации алгоритма случайного леса** для задачи регрессии и его сравнению с эталонной моделью из библиотеки `sklearn`. 


## Ключевые особенности

*   **Полный цикл Data Science:** Проект охватывает все этапы — от очистки "сырых" данных до финального сравнения моделей.
*   **Собственная реализация RF:** Создан класс `ManualRandomForest`, совместимый с интерфейсом `sklearn` (`BaseEstimator`), с нуля реализующий логику ансамбля деревьев решений.
*   **Сравнение с эталоном:** Проведен детальный анализ производительности самописной модели и `RandomForestRegressor` из `sklearn` на тестовых данных.
*   **Продвинутая настройка:** Для обеих моделей выполнен подбор гиперпараметров с использованием `GridSearchCV`.
*   **Анализ важности признаков:** Реализован расчет и визуализация важности признаков. Короче полный feature engineering.

## Детали реализации `ManualRandomForest`

Класс `ManualRandomForest` был разработан для максимального соответствия логике работы `sklearn` и включает следующие ключевые методы:

*   **`__init__`**: Инициализация основных гиперпараметров (количество деревьев, глубина, число признаков и т.д.).
*   **`_get_max_features`**: Логика выбора количества признаков для каждого дерева (поддержка `'sqrt'`, `'log2'`, `float`).
*   **`fit(X, y)`**:
    *   Для каждого дерева создается бутстрап-выборка (опционально).
    *   Случайным образом отбирается подмножество признаков.
    *   Обучается базовое дерево регрессии (`DecisionTreeRegressor`).
    *   Агрегируются значения важности признаков со всех деревьев.
*   **`predict(X)`**: Усреднение предсказаний всех деревьев в ансамбле для получения итогового результата.

## Сравнение моделей и результаты



| Метрика | ManualRandomForest | sklearn RandomForest |
|---|---|---|
| **R² (Коэффициент детерминации)** | 0.9827 | **0.9836** |
| **MAE (Средняя абсолютная ошибка)** | **2953 руб.** | 2965 руб. |
| **RMSE (Корень из MSE)** | 5456 руб. | **5365 руб.** |

**Вывод:** Самописная реализация показала результаты, практически идентичные эталонной версии из `sklearn`, что подтверждает корректность ее реализации.
